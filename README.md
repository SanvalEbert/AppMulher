# Acolher — Informação e Proteção sobre Violência Doméstica

Aplicação web responsiva desenvolvida como produto da atividade de extensão **“Desenvolvimento de sites ou aplicativos sobre violência doméstica”**, vinculada ao curso de Segunda Licenciatura em Informática da UNIASSELVI.

## Acesso ao portal

**Site publicado:** https://sanvalebert.github.io/AppMulher/

## Objetivo

Reunir informações educativas e orientações para apoiar o reconhecimento da violência doméstica e facilitar o acesso a direitos, canais oficiais e serviços da rede de proteção.

## Principais recursos

- informações sobre os tipos de violência previstos na Lei Maria da Penha;
- sinais e indícios de situações de violência;
- orientações para busca de ajuda;
- acesso direto aos números 190, 180, 100 e 129;
- rede de atendimento e serviços de apoio;
- legislação, direitos e perguntas frequentes;
- páginas institucionais sobre o projeto e a privacidade;
- interface responsiva para computadores, tablets e celulares.

## Tecnologias

- React;
- TypeScript;
- Vite;
- React Router;
- Tailwind CSS;
- GitHub Pages.

## Execução local

```bash
pnpm install
pnpm run dev
```

Para gerar a versão de produção:

```bash
pnpm run build
```

## Aviso importante

O Portal Acolher possui finalidade educativa e informativa. Ele não substitui atendimento policial, jurídico, de saúde, psicológico ou de assistência social. Em situação de risco imediato, ligue **190**. Para orientação e denúncia de violência contra a mulher, ligue **180**.
